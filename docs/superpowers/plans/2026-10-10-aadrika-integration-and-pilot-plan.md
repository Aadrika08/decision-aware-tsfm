- Bounded pilot: four existing qualified configurations, hourly context 2,048, horizons 1/24/168, seeds 42/43, batch one, one CPU worker and one BLAS thread; Moirai on the local RTX 4050.

- `origin` is the zero-based first target; `step` is one-based; target position is `origin + step - 1`; context ends exclusively at origin. Horizon specifies the number of target steps.

- Use issue-scoped branches/PRs. Owners close parent issues after their completion conditions; passing CI alone does not close a research task.
